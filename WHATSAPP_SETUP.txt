MealLoop provider leftover features

Files in this patch are laid out relative to your project root. Extract the
ZIP into the MealLoop project folder and allow it to overwrite the listed
existing files. Two new files are added:
  app/providers/expiry.py
  app/providers/whatsapp.py
  tests/test_provider_whatsapp.py

WhatsApp behavior
- If WHATSAPP_ACCESS_TOKEN and WHATSAPP_PHONE_NUMBER_ID are configured,
  MealLoop sends a WhatsApp Cloud API text notification after an NGO request
  is accepted.
- If credentials are absent or the API call fails, MealLoop creates a wa.me
  fallback URL and shows it in the success/flash messages for manual sending.
- NGO phone numbers should be stored in international format, e.g.
  +919876543210. For a 10-digit Indian number, the default country code is 91.

Optional PowerShell environment configuration (use your own real values):
  $env:WHATSAPP_ACCESS_TOKEN = "YOUR_META_ACCESS_TOKEN"
  $env:WHATSAPP_PHONE_NUMBER_ID = "YOUR_META_PHONE_NUMBER_ID"
  $env:WHATSAPP_DEFAULT_COUNTRY_CODE = "91"

Do not commit real access tokens. Configure them in the environment or your
hosting provider's secret settings. No new Python package is required.

Validation
- Python compileall passed for the changed Python files.
- Full pytest and flake8 could not be run in the build environment because
  Flask and flake8 are not installed there. Run the commands below in your
  existing venv311 on Windows:

  .\venv311\Scripts\python.exe -m pytest -q
  .\venv311\Scripts\python.exe -m flake8 app/providers/routes.py app/providers/whatsapp.py app/providers/expiry.py app/recipients/routes.py tests/test_providers.py tests/test_provider_whatsapp.py
